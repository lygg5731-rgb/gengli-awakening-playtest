# 梗力觉醒 · 横版首关试玩

[打开游戏](https://lygg5731-rgb.github.io/gengli-awakening-playtest/)

轻量 2.5D 横版闯关原型：纵深走位、手动三连、浮空击倒、跳跃，三种抽象主动技能。评论区街口 → 热搜广场 → 杠精审判庭，三张独立场景，清怪开门后向右推进，最后挑战终极杠精 Boss。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动与纵深走位 | WASD / 方向键 |
| 普攻三连 | 分次按 J |
| 弹幕开庭：扇形穿透 | U |
| 啊对对对：聚怪盖章 | I |
| 此锅与你有关：远处砸锅 | O |
| 跳跃 / 空中下压 | 空格 / 空中按 J |
| 暂停 | Esc |

手机请横屏，使用左侧摇杆和右侧按钮。按住普攻不会自动连打；收招期间可以预输入。转竖屏会暂停，转回后点击继续。

## 试玩范围

浏览器闯关原型，使用关键姿势和矢量敌人；连续动作帧、正式敌人美术、真机双指与声音/后台兼容仍待补齐。当前版本已通过 393 项工程回归。先前技能与场景改版通过真实 Chromium 正常键盘输入自动通关；20 击败、最大16连击、结束时196/240血量，并检查1200×800、844×390、667×375视口、五个按钮图标、三次换景和旋转暂停。

美术兼容修复：已完成 Chrome 和 WebKit 的图片绘制检查，覆盖正常加载、decode 接口缺失/拒绝，以及 WebP 失败后自动使用 PNG 的路径。开局会等待三个场景和主角全部姿势准备完成，并显示加载进度。发布页脚本带内容版本号，避免旧缓存继续运行旧加载器。这些结果属于自动浏览器验证，WebKit 不等于实体 iPhone/iPad 验收。

已知小问题：浏览器挂起声音后，继续/开启声音可能未恢复音效；最大纵深下，宽动作姿势在画布边缘可能部分裁切。

本仓库只包含浏览器运行包和资源校验清单。朋友打开上方链接即可试玩，无需下载或安装；不包含开发工作区、旧模式、美术留档或个人配置。
