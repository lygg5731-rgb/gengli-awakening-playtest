# 梗力觉醒 · 横版首关试玩

[打开游戏](https://lygg5731-rgb.github.io/gengli-awakening-playtest/)

轻量 2.5D 横版闯关手感原型：纵深走位、手动三连、浮空击倒、跳跃、三种主动技能，两段街区清怪后挑战终极杠精 Boss。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动与纵深走位 | WASD / 方向键 |
| 普攻三连 | 分次按 J |
| 穿透 / 冲拳 / 解围 | U / I / O |
| 跳跃 / 空中下压 | 空格 / 空中按 J |
| 暂停 | Esc |

手机请横屏，使用左侧摇杆和右侧按钮。按住普攻不会自动连打；收招期间可以预输入。转竖屏会暂停，转回后点击继续。

## 试玩范围

浏览器首关原型，使用关键姿势和矢量敌人；连续动作帧、正式敌人美术、真机双指与声音/后台兼容仍待补齐。已完成正常手动通关与桌面、手机视口检查，工程 380 项回归通过。最终规则修整后另做了针对性实际操作验证。

已知小问题：浏览器挂起声音后，继续/开启声音可能未恢复音效；最大纵深下，宽动作姿势在画布边缘可能部分裁切。

本仓库只包含浏览器运行包和资源校验清单。朋友打开上方链接即可试玩，无需下载或安装；不包含开发工作区、旧模式、美术留档或个人配置。
