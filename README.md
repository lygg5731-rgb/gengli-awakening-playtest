# 梗力觉醒 · 横版首关试玩

[打开游戏](https://lygg5731-rgb.github.io/gengli-awakening-playtest/)

轻量 2.5D 横版闯关原型：纵深走位、手动三连、浮空击倒、跳跃，三种抽象主动技能。评论区街口 → 热搜广场 → 杠精审判庭，三张独立场景，清怪开门后向右推进，最后挑战终极杠精 Boss。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动与纵深走位 | WASD / 方向键 |
| 普攻三连 | 分次按 J |
| 弹幕开庭：扇形穿透 | U |
| 啊对对对：聚怪盖章 | I |
| 此锅与你有关：远处砸锅 | O |
| 跳跃 / 空中下压 | 空格 / 空中按 J |
| 暂停 | Esc |

手机请横屏，使用左侧摇杆和右侧按钮。按住普攻不会自动连打；收招期间可以预输入。转竖屏会暂停，转回后点击继续。

## 试玩范围

浏览器闯关原型，主角和敌人使用绘制好的关键姿势。红温键盘侠持键盘、急眼暴走仔戴拳套、弹幕喷子持扩音炮、终极杠精戴冠冕持大槌；四种敌人各有八个姿势，Boss 横扫、冲锋、砸地分别呈现。连续动作帧、真机双指与声音/后台兼容仍待完善。

场景弹幕：热搜广场飘过围观评论和点赞，杠精审判庭的对线评论更密。后两段达到 8 连击后有喝彩，每 8 次有效命中进入下一档回应；Boss 蓄力和攻击时弹幕明显变淡，暂停会冻结，重开会清空。击败 Boss 后有短暂“拿下”刷屏和结算回应。弹幕绘制在角色、场景招牌和攻击预警后方。

当前场景弹幕版本已通过 405 项工程回归。真实 Chrome 正常键盘输入自动通关三段街区，实际观察到后两段评论、连击喝彩、Boss 预警淡出和胜利刷屏；20 击败、最大 16 连击、结束 188/240 血量。Chrome/WebKit 的 iPhone 15 Plus 横屏独立渲染检查通过，667×375 的胜利面板没有溢出。

美术兼容：保留 PNG 回退和加载进度，开局等待三个场景、主角全部姿势和四种敌人图集准备完成。新敌人已经通过 Chrome 与 WebKit 的正常图片绘制检查，以及 iPhone 15 Plus 横屏配置下的 WebKit 触控技能和强制 PNG 回退检查。发布页脚本带内容版本号，避免旧缓存继续运行旧加载器。用户已在实体 iPhone 15 Plus 确认此前主角和技能显示恢复；本次敌人美术的真机反馈尚未收到。

试玩复查修正：继续战斗和开启声音会重新激活浏览器音频；战斗区中部镜头保持稳定，主角贴边时在当前区域内小幅平移，保留完整姿势；同一纵深的敌人与主角重叠时，主角优先可见。不同纵深的前后遮挡保持。声音恢复已在 Chrome 中验证；实体 iPhone 的声音和后台恢复仍待验收。

本仓库只包含浏览器运行包和资源校验清单。朋友打开上方链接即可试玩，无需下载或安装；不包含开发工作区、旧模式、美术留档或个人配置。
